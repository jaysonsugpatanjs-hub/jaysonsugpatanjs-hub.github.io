E — Environment Setup · Complete

Build safely before connecting live systems

The project now has a documented minimum stack, test-vs-production rules, synthetic test data and explicit credential-handling controls. Real secrets remain outside GitHub by design.

GitHub Pages

Public portfolio and static demo front end.

Public

HubSpot

CRM, forms, contacts, companies and deals.

System of record

n8n

Workflow automation and orchestration.

Automation

OpenAI

Structured qualification and scoring.

Secure credentials only

Local / Draft

Documentation, HTML/CSS changes and synthetic data preparation.

Test / Demo

HubSpot demo records, n8n test webhooks and AI prompt tests.

Production / Live

Only after workflows are tested, published and reviewed. Real credentials are never exposed in the public repo.

Security checklist

✓ Enable MFA wherever supported.
✓ Use separate test records and a demo/test pipeline.
✓ Never commit API keys, tokens, passwords or confidential customer data.
✓ Store OpenAI and other secrets only in secure platform credentials.
✓ Inspect exported n8n JSON for embedded credentials before publishing.
✓ Use test webhook URLs while debugging; switch to production only after the workflow is active.
