- `hubspot-pipeline.png`
- `n8n-workflow.png`
- `ai-score-result.png`

## Screenshot safety rules

Before adding a screenshot:

1. Use synthetic/demo records where possible.
2. Hide or remove API keys, tokens, credentials and private URLs.
3. Remove or replace real personal/customer information.
4. Crop the image to the implementation evidence that matters.
5. Name the file descriptively so it can be referenced from the README and case study.

Screenshots will be added only after the corresponding system milestone is actually implemented.
