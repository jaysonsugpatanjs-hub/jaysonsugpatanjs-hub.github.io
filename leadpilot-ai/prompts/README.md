# Prompts

This folder stores versioned AI prompt specifications used by LeadPilot AI.

Planned artifact from the implementation guide:

- `lead-qualification-v1.md`

Each prompt file should document:

- purpose;
- input fields;
- expected structured output;
- scoring/qualification instructions;
- confidence or human-review rules where relevant;
- version/change notes.

Do not store API keys, private credentials or confidential customer data in prompt files.
